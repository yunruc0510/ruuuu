## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
`"4"` 加上引號後屬於字串（`str`）型別，在 Python 中代表的是「文字字元」，而不是可以進行數學計算的數值。如果直接用應付總額（數字）去除以 `"4"`（字串），Python 會產生型別錯誤（`TypeError`），無法完成除法運算。因此必須先使用 `int("4")` 將其轉換為整數 `4`，才能用來計算每人分攤的費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
如果改成先扣除折價券再計算服務費，第一組的計算過程會變成：
- **折價後餐費**：$1200 - 100 = 1100$ 元
- **服務費**：$1100 \times 0.10 = 110$ 元
- **應付總額**：$1100 + 110 = 1210$ 元

**與題目結果不同的原因：**
題目規定服務費必須以「原始餐費 $1200$ 元」計算（服務費為 $120$ 元），算完服務費後才扣除折價券 $100$ 元，因此應付總額為 $1200 + 120 - 100 = 1220$ 元。若先扣掉折價券，計算服務費的基準金額就變少了 $100$ 元，導致服務費少算了 $100 \times 0.10 = 10$ 元，最終總金額也跟著少了 $10$ 元。
